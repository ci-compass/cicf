# CICF Week 2

The goals for the week 2 lab are:

1. Be able to work with Python from the command line.
2. Use NumPy

## Tutorial

Open the [week02-tutorial.ipynb](./week02-tutorial.ipynb) notebook in JupyterLab and work through it.
Run each code cell with **Shift+Enter** and follow the explanations.

For a more in-depth introduction to Python, see [python.md](./python.md).

## Exercises

Complete the exercises in `exercise-1.py` and `exercise-2.py`.
You can check your work by running `make` in the terminal.
